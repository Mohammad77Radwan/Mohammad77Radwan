* **[Go Distributed Orderbook](https://github.com/Mohammad77Radwan/go-distributed-orderbook)** A high-throughput, concurrent financial matching engine and real-time order book simulator built entirely in Go. 
    > *Focus: Low-latency system design, concurrency, financial algorithms.*

* **[Enterprise RAG Pipeline](https://github.com/Mohammad77Radwan/enterprise-rag-pipeline)** An asynchronous, enterprise-grade Retrieval-Augmented Generation (RAG) pipeline built in Python. Features modular vector search and background task processing.
