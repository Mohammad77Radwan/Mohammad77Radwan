# Mohammad Radwan
### Développeur Logiciel & Étudiant en Ingénierie | Saint-Étienne, France

<br>

Je suis un développeur logiciel spécialisé dans les systèmes backend à haute performance, l'architecture web moderne et les principes du code propre (clean code). Mon travail fait le pont entre l'ingénierie backend à faible latence et des interfaces dynamiques orientées utilisateur. Je suis particulièrement attiré par les défis techniques complexes, la programmation concurrente, les systèmes distribués et l'intégration de l'IA.

### Projets Techniques Récents

* **[Go Distributed Orderbook](https://github.com/Mohammad77Radwan/go-distributed-orderbook)** Un moteur de correspondance financière concurrent à haut débit et un simulateur de carnet d'ordres en temps réel, entièrement développé en Go. 
    > *Focus : Conception de systèmes à faible latence, concurrence, algorithmes financiers.*

* **[Enterprise RAG Pipeline](https://github.com/Mohammad77Radwan/enterprise-rag-pipeline)** Un pipeline asynchrone de génération augmentée par la recherche (RAG) de niveau entreprise, développé en Python. Comprend une recherche vectorielle modulaire et un traitement de tâches en arrière-plan.
    > *Focus : Architecture IA, pipelines de données, calcul asynchrone.*

* **[Mindful Journal](https://github.com/Mohammad77Radwan/MINDFUL-JOURNAL)** Une application de journalisation axée sur la confidentialité, développée avec TypeScript. Elle exploite l'IA intégrée de Chrome pour un traitement des données local et sécurisé côté client.
    > *Focus : Privacy-by-design, intégration LLM locale, gestion sécurisée de l'état.*

* **[Morefix WebStore](https://github.com/Mohammad77Radwan/Morefix_WebStore)** Une architecture de plateforme e-commerce moderne utilisant Next.js et React. Intègre Firebase Auth pour des sessions utilisateur sécurisées et Tailwind CSS pour des systèmes de conception évolutifs.
    > *Focus : Intégration full-stack, routage dynamique, authentification.*
